# Calendar Web Frontend

A responsive web calendar app with Google Calendar-style arrangement, built with React, Vite, Bootstrap 5, and Tabler icons.

## Features
- **Views**: Month, Week, Day, and Agenda schedule views.
- **Tanzania Holidays**: Built-in official Tanzanian public holidays under Other calendars.
- **Multiple Calendars**: Create custom calendars, toggle visibility, and assign colors.
- **Theme**: Light / Dark mode persistence.
- **Shortcuts**: Keyboard shortcuts (`c` for create, `t` for today, `d`/`w`/`m`/`a` for views).

## Scripts
- `npm run dev`: Start Vite development server
- `npm run build`: Build for production
- `npm run preview`: Preview production build
- `npm run test`: Run smoke test suite
